KARTU 100 / TAHAP 2

Satu spreadsheet, satu server.

Lobby untuk 2-4 pemain. Tidak perlu login Google untuk bermain.

Masuk server

Gunakan tautan server yang sudah disiapkan pengelola.

Nama unik di server ini. Nama bukan kata sandi.

Ada sesi tersimpan untuk server ini. Lanjutkan dengan identitas yang sama, bukan mendaftar ulang.

Masukkan tautan spreadsheet dan nama untuk bergabung.

Pemain terdaftar

    Sinkronisasi sekaligus heartbeat sekitar setiap 10 detik. Tanpa heartbeat selama 60 detik, pemain dikeluarkan dan semua pemain tersisa menjadi belum siap saat request berikutnya. Tab latar belakang dapat ditunda browser. Semua siap belum memulai permainan pada tahap ini.

    Penyiapan server (pengelola)

    Pemain tidak perlu mengisi bagian ini. Pengelola menyiapkan backend dan spreadsheet sebelum membagikan tautan server.

    Konfigurasikan sekali oleh pengelola. Endpoint bukan kredensial. Pemilik spreadsheet harus berbagi akses Editor kepada akun khusus game.

    Gunakan tautan spreadsheet pada form di atas. Inisialisasi tidak mendaftarkan pemain dan tidak menimpa server yang sudah valid.

    Sesi disimpan di browser ini per endpoint dan spreadsheet. Jangan hapus data browser saat masih terdaftar. Semua pemegang tautan bisa mencoba masuk. Editor spreadsheet dapat membaca/mengubah data game. Gunakan akun Google khusus game, bukan akun pribadi.
